# 元策 UI v3 设计原型

`/web` 工作台的第三版 UI 设计原型。**这是原型，不是实现。**

## 定位与边界

| | 说明 |
|---|---|
| 是什么 | 纯 HTML + CSS + 原生 JavaScript 的可交互设计稿，零构建、零第三方依赖 |
| 数据 | 全部为静态 mock（`scripts/mock/data.js`），不发起任何后端请求 |
| 不做什么 | 不改动 `frontend/packages/`、`web/`、`desktop/`、`api/` 的任何现有代码 |
| 时间管理 | 沿用现网实现。侧边栏「时间管理」入口带「现网」标记，跳转现网页面，v3 不提供其重设计版本 |
| 生产链路 | 不参与 `web/` 与 `desktop/` 的 Vite 构建，不进入正式环境产物 |

设计定稿后需要把设计回迁到 `frontend/packages/ui` 组件层（`web/` 与 `desktop/` 共用同一套 UI 包）。
回迁属于另立规格的工作，本模块只负责把设计规则定下来。

## 启动

原生 ES Module 不能通过 `file://` 协议加载，必须用静态服务打开：

```bash
# 在仓库根目录执行
python3 -m http.server 4183 --directory ui-v3
```

然后访问 <http://127.0.0.1:4183/>。

不需要 `make dev-*`，不需要启动 `api/`，不需要 Docker。

## 目录结构

```text
ui-v3/
├── index.html            # 唯一入口，承载壳层与内容容器
├── assets/icons.svg      # SVG 图标符号表（统一 24×24，禁止 emoji）
├── styles/
│   ├── tokens.css        # 设计令牌唯一来源：色板/间距/字号/圆角/阴影/动效/层级
│   ├── base.css          # reset、排版、焦点态、可访问性、reduced-motion
│   ├── layout.css        # 应用壳层布局与通用排布原语
│   └── components.css    # 按钮/表单/表格/徽标/面板/标签页/弹层等组件
└── scripts/
    ├── app.js            # 入口：组装壳层、注册路由、响应 hash 变化
    ├── router.js         # hash 路由
    ├── shell.js          # 侧边栏 + 顶栏
    ├── ui.js             # DOM 构建原语与通用组件工厂
    ├── mock/data.js      # 静态 mock 数据
    └── pages/            # 各页面模块
```

## 设计约定

### 视觉基调

深色品牌侧栏 + 冷紫页面底色 + 靛蓝主色 + 白色浮层卡片。
层级靠**留白与柔和阴影**建立，不靠满屏描边。

| 角色 | 取值 |
|---|---|
| 主色（靛蓝） | `#4f46e5`，品牌渐变 `#6366f1 → #8b5cf6` |
| 页面底色 | `#f4f5fb` |
| 承载面 | `#ffffff` / `#fafbfe` / `#f1f3f9` |
| 侧栏 | `#151829 → #1d2138` 渐变 |
| 文字三级 | `#151827` / `#4f5568` / `#676d7f` |
| 状态色 | 翡翠 `#059669`、琥珀 `#d97706`、红 `#dc2626`、蓝 `#2563eb`、紫 `#7c3aed`、青 `#0d9488` |

### 令牌

所有颜色、间距、字号、圆角、阴影、动效时长只在 `styles/tokens.css` 定义，页面样式一律引用变量。
这条规则是为了让回迁 React 时有一张可一一对应的令牌表。

- 颜色分三层语义：`--surface-*`（承载面）、`--line*`（分隔线）、`--text-*`（文字），
  另有 `--brand-*`、`--success/warning/danger/info/violet/teal/neutral-*` 状态色与 `--nav-*` 侧栏色。
- 间距刻度：2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- 字号刻度：11 / 12 / 13 / 14 / 15 / 16 / 18 / 22 / 28。
- 圆角刻度：6 / 8 / 10 / 14 / 18 / full。
- 控件高度：28 / 32 / 36，输入框 36，表格行高 46，表头 40。

### 密度

v3 的目标是提高信息密度同时保持可读：表格行高 46px，表头 40px，
关键数字用 28px / 700，等宽数字保证纵向对齐；元信息降到 12–13px 但对比度全部 ≥ 4.5:1。

### 颜色不单独承载语义

状态用「圆点 + 文字」双通道表达，优先级用「形状 + 文字」表达，未读用文字标签 + 强调色。
即使在灰度打印或色觉障碍场景下，信息也不会丢失。

### 动效

功能性微交互 130–200ms（hover、focus、导航态、抽屉），页面入场位移 320ms，
全部在 `prefers-reduced-motion: reduce` 下降为 0.01ms。不引入任何动画库。

### 侧栏结构

分组依次为：概览 / 项目 / 交付 / 协作 / 工具 / 系统，**不放底部账户块**——
账户信息在顶栏头像菜单里，重复展示只会占空间。

「时间管理」是常规导航项，位置在「工具」分组内（仍带「现网」标记，跳转现网页面），
与其它一级入口保持一致，不做特殊隔离。

### 顶栏控件

顶栏是半透明毛玻璃，控件若用同色系浅底会与背景糊在一起。
搜索框、项目切换器、通知与账户按钮统一用「白底 + 1px `#ccd3e2` 描边 + 微阴影」，
确保在顶栏上清晰可辨。

### 下拉一律不用原生 `<select>`

原生下拉的展开菜单由浏览器绘制，样式无法与设计系统对齐，在半透明顶栏上还会弹出系统级灰色菜单。
`ui-v3` 内没有任何原生 `<select>`，统一使用 `ui.js` 导出的 `select()` 组件：

```js
select({
  value: currentProject.key,
  ariaLabel: '切换当前项目',
  size: 'pill',          // 顶栏用胶囊形态，筛选条用默认形态
  width: '168px',
  items: [{ value: 'P261102793662', label: '零售系统', hint: 'P261102793662' }],
  onChange: (value) => { /* ... */ },
});
```

行为：点击或 Enter/Space/↓ 打开，↑↓ 移动，Enter 选中，Esc 关闭并把焦点还给触发器，点击外部关闭。
语义：`aria-haspopup` / `aria-expanded` / `role="listbox"` / `role="option"` / `aria-selected`。

### 可访问性

- 全部可交互元素有可见焦点环（`:focus-visible` 描边，输入控件用描边 + 边框变色）。
- 正文对比度 ≥ 4.5:1，已按 `tokens.css` 逐对核验（24 组组合全部通过）。
- 响应 `prefers-reduced-motion`，关闭非必要动效。
- 响应式断点 375 / 768 / 1024 / 1440：窄屏侧边栏转为抽屉，宽表由横向滚动容器承载。

## 与现网的主要差异

| 维度 | 现网 | v3 |
|---|---|---|
| 一级导航 | 顶部横向 9 项 + 下拉 | 左侧固定深色侧栏分组（概览/项目/交付/协作/系统） |
| 顶栏 | 导航 + 项目切换 + 搜索 + 通知 + 账户挤在一行 | 只留搜索、项目切换、通知、账户 |
| 层次表达 | 满屏细线描边 | 留白 + 柔和阴影，页面底色带微紫倾向 |
| 品牌色 | 灰蓝 `#376b9b` | 靛蓝 `#4f46e5` + 靛紫品牌渐变 |
| 概览指标 | 4 张大卡片占满一行 | 彩色图标磁贴指标卡，悬浮上浮 |
| 项目列表 | 大表格 | 卡片网格，含首字母色块、成员头像组、待处理拆分 |
| 工作项列表 | 表格列宽偏大，稀疏 | 列压紧 + 「需求/任务/Bug」拆分列 + 勾选批量操作条 |
| 状态表达 | 以彩色圆点为主 | 圆点 + 文字胶囊，优先级用形状 + 文字 |
| 详情页 | 单栏堆叠 | 主栏 + 右侧属性栏分栏 |
| 窄屏 | 未适配 | 抽屉导航 + 横向滚动宽表 |
