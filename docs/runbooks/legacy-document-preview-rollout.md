# legacy doc/ppt 实验预览手册（已废弃）

该手册对应的实验性预览链路已废弃。`doc/ppt` 现在与 PDF、DOCX、PPTX、XLSX 等格式一起由
Flyfish File Viewer 统一预览，默认直接可用，不再依赖
`YUANCE_EXPERIMENTAL_LEGACY_PREVIEW_ENABLED` 开关，也不再显示“实验性预览”或水印提示。

当前验证与部署说明见：

- `docs/runbooks/document-preview-frontend-validation.md`
- `docs/runbooks/production-deployment.md`
- `docs/plans/2026-08-31-refactor-file-viewer-preview-stack-plan.md`
