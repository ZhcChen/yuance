# 项目资料正文目录布局调整计划

## 目标

统一项目资料详情正文目录的条目行高与间距，标题保持单行并以省略号截断；目录与正文之间增加可拖拽、可键盘调整的分隔条，宽度保存在当前浏览器本地。

## 实施

1. 为开启正文目录的 `RichTextContent` 增加可选宽度调整能力；当前仅项目资料详情启用。
2. 将分隔条宽度限制在合理范围，提供键盘操作与可访问属性，并从 `localStorage` 恢复和保存宽度。
3. 调整资料详情目录 CSS，固定单行条目样式、层级缩进和分隔条交互态。
4. 增加宽度边界及目录交互的回归验证，并运行前端相关检查。

## 验收

- 目录标题不换行，超出宽度时显示省略号，条目间距与行高一致。
- 鼠标拖动分隔条可改变目录宽度；键盘左右方向键可微调，Home/End 可调至边界。
- 刷新后恢复已保存宽度；无效或越界存储值不会导致布局异常。
- 空正文后通过编辑填入内容时，目录也能恢复既有本地宽度。
- 非资料详情的 `RichTextContent` 调用保持原样。

## 执行结果

- 2026-09-23 完成目录单行省略、桌面分隔条拖拽与键盘调整、本地宽度持久化；窄屏保留原有顶部横向目录。
- UI 单元检查 88 项、应用壳检查 10 项、桌面 renderer 构建和资料详情浏览器回归 3 项通过。
- 复核中发现并修复空正文后续填入内容时漏恢复宽度的问题；详见 `docs/reviews/2026-09-23-001-project-resource-outline-resize-review.md`。
