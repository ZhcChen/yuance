# 项目体检问题整改

状态：方案待确认
来源：`docs/reviews/2026-11-24-project-health-check.md`（2026-11-24 全项目体检）；用户要求“你出方案”。

## 目标与范围

按风险优先级修复体检确认的问题：先消除权限漏洞、用户数据丢失与单点数据风险，再补可观测性、并发正确性与性能，最后处理交互细节与结构性重构。每个批次独立交付：测试、提交、部署、复核。

不做：

- 不改变已确认的产品行为（例如新建工作项上传附件不依赖标题）。
- 不在一个批次里混合重构与缺陷修复；P2 重构单独立项、分步推进。
- 服务器侧变更（备份定时、网关配置、发布脚本在服务器上的行为）在执行当次单独征得授权。

## 用户场景与验收

### US1：权限边界正确

- Given：项目维护者
- When：通过“添加成员”传入负责人账号或 `owner` 角色
- Then：请求被拒绝，负责人角色不变
- 关键边界：只读成员不能关闭工作项（见决策 D3）。

### US2：后台刷新不丢失用户状态

- Given：用户已解锁受保护资料 / 正在编辑个人资料 / 已提交资料库筛选
- When：收到通知、SSE 重连等触发后台刷新
- Then：解锁状态、未保存输入、已提交筛选均保持不变

### US3：数据可恢复

- Given：qfy-test2 主机或磁盘整体损坏
- When：按 Runbook 从异地备份恢复
- Then：数据库与文件主密钥可在新主机恢复，已加密附件可解密；恢复演练每季度执行并留档

### US4：故障可发现、可定位

- Given：数据库不可用或请求发生 5xx
- When：外部探活与运维排查
- Then：公网 `/api/readyz` 如实返回 503；服务端日志含 request id、路径、状态、耗时与错误详情；前端只看到通用提示与 request id

### US5：大附件与并发不拖垮服务

- Given：用户下载 / 预览大体积加密附件，或多人同时修改工作项
- Then：内存占用与文件大小无关（按块流式）；并发写不出现 `database is locked` 500，状态流转不基于过期状态

## 功能要求

- FR-001：`add_project_members` 不得授予 `owner`，不得修改已有成员角色（已存在时报错或跳过）。
- FR-002：只读成员不能关闭工作项，详情视图的 `can_close_work_item` 同步约束。
- FR-003：后台刷新（`refresh` 模式）保留：已解锁资料的详情与附件、个人资料表单输入、已提交的资料库筛选；SSE 与通知回调调用最新的 `loadRouteState`。
- FR-004：SSE 首次连接不触发全量刷新，仅断线重连后补拉。
- FR-005：深色模式在页面加载前生效；全局错误 toast 只用于未被调用方处理的写操作失败。
- FR-006：生产环境安全主密钥缺失或为默认值时拒绝启动；移除未使用的配置与依赖。
- FR-007：5xx 响应不返回内部错误原文，返回通用文案与 request id；服务端记录结构化请求日志与错误日志。
- FR-008：先读后写的事务使用 `BEGIN IMMEDIATE` 并在事务内校验；状态类 UPDATE 带前置条件并检查影响行数；会话 / Token 的 last-seen 写入节流。
- FR-009：补充操作记录与审计列表索引。
- FR-010：登录与资料解锁限流；用户不存在时同样执行一次密码校验以抹平时间差；Argon2 在阻塞线程池执行。
- FR-011：附件下载与预览按块流式读取与解密，解密在阻塞线程池执行。
- FR-012：数据库与密钥每日在线备份，加密后同步异地；本地与异地均有保留策略；恢复演练脚本。
- FR-013：网关不把应用 503 改写为 200；补全安全响应头（应用层 + 网关 HSTS）。
- FR-014：发布链路：镜像按提交 SHA 标签、迁移成功后再切换；部署锁；健康检查重试并经公网验证；SSE 响应停机信号。
- FR-015：通用弹窗支持放弃保护；窄屏收起的侧栏不可聚焦；手机触控区域与筛选栏截断。

## 成功标准

- SC-001：每个 FR 有对应自动化测试（Rust 集成测试 / 前端单测 / e2e）或演练记录。
- SC-002：全量 `make test`、e2e 与视觉回归通过；每批次部署后线上验证留档。
- SC-003：P0 全部完成后，复核体检报告中 P0 项均可标记为已解决。

## 风险与验证要求

- 事务改造与限流涉及核心写路径：逐函数改造并补并发测试；分批上线。
- 附件流式改造涉及加密格式：以现有分块格式为准，新增大文件与 Range 用例，确认与旧数据兼容。
- 备份与网关为服务器变更：先在测试路径演练，执行当次授权，保留回退。
- 独立代码复核，结论写入 `docs/reviews/`。

## 决策（推荐，待用户确认）

- D1 异地备份目标：阿里云 OSS 独立 Bucket（与业务 Bucket 分离、不同 AccessKey、仅允许写入与读取备份前缀、开启版本控制与生命周期）。备份文件在服务器端用 `age` 公钥加密后上传，私钥由用户离线保管；文件主密钥与安全主密钥另行离线保存一份。
- D2 服务器操作：批次 D 执行前单独确认，过程全程只读核查后再变更，变更前备份原配置。
- D3 只读成员关闭工作项：不允许；“任何人可关闭”限定为对项目有写权限的成员（负责人、维护者、成员）。
