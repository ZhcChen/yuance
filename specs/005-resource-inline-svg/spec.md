# 资料正文受控 SVG 展示

状态：本机修复与验收通过，已正式发布，正式页面登录验收待完成
来源：2026-10-09用户反馈，项目P260713139801资料30附件189、193、194、192无法显示。

## 目标与范围

已上传SVG必须在资料正文正常显示，包括编辑器生成的图片及OpenAPI已保存的裸图片引用。准确说明维护AI应写入的HTML，保留现有正文和附件，不创建平行资料、不扩大HTML允许属性或SVG执行权限。

## 用户场景与验收

### US1：读者查看含附件图片的资料

- 优先级：P1
- Given：有权限用户阅读包含已上传SVG的现有资料。
- When：打开详情页或点击图片预览。
- Then：正文及预览显示完整图片，四张图自然尺寸均大于零，无媒体加载或解密错误。
- 关键失败或边界场景：无效/无权限/损坏附件显示加载失败；历史明文与加密文件均兼容；切换资料释放临时图片源。

### US2：维护AI写入有效图片引用

- 优先级：P1
- Given：已经上传并确认状态的当前资料图片附件。
- When：按照Skill提供的HTML通过CLI更新并回读资料。
- Then：有效引用保留，正文和附件原内容不变；明确上传/下载成功不等于页面展示验收。

## 功能要求

- FR-001：标准附件容器及媒体自身携带附件ID的历史引用均使用同一受控预览流程。
- FR-002：Web复用附件鉴权、归属检查、明文/密文校验及解密；不把签名URL或密钥持久化到正文。
- FR-003：SVG以图片方式显示，保留HTML清洗与SVG安全校验，不放开脚本/事件/object/iframe或data媒体写入。
- FR-004：异步失败显示已有错误状态，不降级到下载地址；卸载与路由切换释放Blob/桌面预览能力。
- FR-005：Skill、CLI文档说明figure标准格式与保存地址/实际预览源的区别；本机安装文档同步。
- FR-006：不删除、替换或重建正式资料/附件；实际登录页面核验目标四图的网络请求及控制台。

## 成功标准

- SC-001：本机登录详情页中标准容器、裸图片、加密及明文SVG均显示，自然宽高大于零，原始download请求不发生。
- SC-002：失败与卸载测试通过，资料章节和普通图片显示不回归。
- SC-003：正式页面四张图均通过实际登录验收，保存正文保持原样；与本机测试/发布状态分别记录。
- SC-004：维护AI可按准确HTML与现有CLI参数写入有效引用，无需新CLI命令或参数。
