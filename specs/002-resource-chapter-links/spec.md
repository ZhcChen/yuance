# 资料同文档章节引用

状态：已完成，实现与验收已提交推送（`e4fbec0`）
来源：用户反馈 BI 测试手册的表格引用和正文目录无法跳转。

## 目标与范围

资料维护者通过编辑器或 OpenAPI 创建章节引用；读者通过正文引用与自动目录定位同一章节。适用于 HTML 资料正文，不扩大通用 HTML 权限、不部署正式环境、不修改外部项目资料。

## 用户场景与验收

### US1：维护并阅读可定位的资料

- 优先级：P1
- Given：资料包含表格引用、正文目录及重复标题。
- When：通过编辑器或 OpenAPI 保存、回读，并在详情页点击引用。
- Then：正文链接和左侧目录定位同一标题，目标可见且不被固定顶部遮挡。
- 关键失败或边界场景：标题改名、重排不影响持久化引用；重复标题具有不同标识；目标删除后不误跳另一同名章节；外部链接不被接管。

## 功能要求

- FR-001：h1-h6 具有文档内唯一稳定标识；合法已有标识保留，缺失自动补齐，重复标识保留首个并为后者分配新标识。
- FR-002：正文片段引用与左侧目录复用相同目标解析及正文滚动逻辑，保留顶部留白，不滚动整个页面或目录。
- FR-003：编辑器支持选择章节创建链接，保存并再次编辑不丢失标识；OpenAPI 支持明确 HTML 写法及保存回读。
- FR-004：标题改名和重排保留标识；删除后旧引用无效，不按同名标题猜测重绑；整段替换正文需维护者保留既有标识。
- FR-005：保持脚本、事件属性及危险 URL 清洗，不放开通用 id/name 或任意属性；外部链接及附件行为不回归。
- FR-006：历史无标识资料在阅读时可使用自动目录，编辑保存后获得持久化标识；被旧清洗删除的锚点不承诺自动恢复，无效引用提供可理解反馈。
- FR-007：对外说明准确 HTML/API/CLI 写法及标识生命周期；核对 OpenAPI、CLI 与 Skill 所需同步。

## 成功标准

- SC-001：真实 API 创建、回读、编辑保存、改名重排后，正文引用和标题标识仍一致。
- SC-002：真实详情页面点击表格引用、正文目录及左侧目录，定位同一目标且目标位于正文可视范围。
- SC-003：重复标题、删除目标、历史资料和危险 HTML 聚焦测试通过；现有目录宽度回归通过。

## 风险与验证要求

后端清洗与幂等测试、编辑器和定位聚焦测试、真实 API/Playwright 浏览器验收；独立审查安全清洗、持久化兼容与定位边界。浏览器使用项目 Playwright 无头运行时。不得用 mock 保存证明后端有效。

## 未决事项

无。重复显式标识的引用指向首个；新增复制标题获得新标识。历史任意失落锚点不猜测恢复。
