description: 按计划执行一个阶段或连续执行单元
argument-hint: "[计划路径或执行范围]"

执行 `${@:-当前对话中已确认的计划阶段}`。

遵守项目根目录 `AGENTS.md`。

1. 开始改文件前执行 `git status --short`，确认工作区中已有改动的归属。
2. 定位对应的 `docs/plans/` 文档，确认本次只覆盖一个阶段或一组连续执行单元；长任务使用 `/goal` 绑定当前阶段。
3. 先阅读受影响代码和现有测试，再做小而可验证的改动，不进行无关重构。
4. 根据改动范围执行聚焦验证；涉及第三方库或框架的当前用法时优先使用 Context7，涉及浏览器问题时优先使用 `chrome-devtools`。
5. 对照计划复核结果，必要时续写计划状态或将关键经验交给 `/compound` 沉淀。
6. 达到最小可解释闭环后，严格按照 `AGENTS.md` 的 Git 规则检查、暂存、提交并推送本轮相关文件。

遇到缺决策、缺权限或危险不可逆操作时，说明阻塞原因并等待用户输入。
